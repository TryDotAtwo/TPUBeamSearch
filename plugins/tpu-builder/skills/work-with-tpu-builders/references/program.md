# TPU Builders Program reference

Last checked: 2026-09-23. These links and terms were read from the members-only handbook dated 2026-09-18 and the welcome email. Verify live pages before using them.

- Welcome email: accepted member; Google Groups membership and TPU Builders Chat invitation provided.
- [Members-only handbook](https://docs.google.com/document/d/1bebewSvoosBHUWyVe8i221TGO3Mrx8YXoqIfsDQO8tI/edit): one high-quality technical artifact each quarter; share knowledge and feedback. Do not republish the handbook.
- [Monthly activity form](https://forms.gle/8W44DtHbdqvzTsjn6): report recent work, preferably in English with public resources and 3–5 relevant tags. The September reminder requested submission by month end. Reported activities are normally reviewed in the first two weeks of the next month.
- [Google Cloud credit request form](https://forms.gle/ziqTCYU9MyoJbR5q7): requires full name, email, country, new/follow-up status, billing account ID, project ID and number, project description, educational sharing plans, amount in USD, Google employment status, and expected resources. Affiliation is optional. The handbook recommends $1,000 initially and says deposits typically take about two weeks after submission and approval.
- [TPU Builders getting started guide](https://docs.google.com/document/d/1u2W79sxupb1Nm53zONbsnjyHzwcjuu-76urThl-MhRs/edit): setup after credits arrive.
- Program support: tpu-builders-support@google.com. The credit form itself lists tpu-builders-contact@google.com for questions.
- [Billing credits page](https://console.cloud.google.com/billing/credits) and [budget-alert guide](https://docs.cloud.google.com/billing/docs/how-to/budgets): monitor charges; alerts do not stop spending. No TPU resources should be left running based only on an alert.

For this repository, use `docs/TPU_ARCHITECTURE.md`, `docs/TPU_PORT_LEDGER.md`, published experiment reports, and source SHA when describing TPUBeamSearch. An isolated kernel result is not end-to-end beam performance.
